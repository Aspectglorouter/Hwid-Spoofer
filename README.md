# 🛡️ HWID Spoofer

**HWID Spoofer** is a powerful tool designed to modify and spoof your computer's hardware identifiers (HWID). It helps protect your digital privacy, bypass hardware bans (HWID bans) in various games/anticheats, and automate system configuration randomization.

## ✨ Features

* **SMBIOS & BIOS Spoofing**: Randomizes motherboard, BIOS, and system UUID serial numbers.
* **Disk Serial Changer**: Spoofs serial numbers for HDD, SSD, and NVMe drives.
* **MAC Address Masking**: Automatically alters network adapter physical addresses.
* **Registry Cleaner**: Wipes tracking files, cached identifiers, and anticheat leftovers.
* **GPU Spoofing**: Modifies display adapter registry identifiers.
* **One-Click Restore**: Safely back up and restore your original hardware IDs.

## 🛠️ System Requirements

* **Operating System**: Windows 10 / 11 (x64 architectures)
* **Privileges**: Administrator rights are strictly required.
* **Platform**: Works on both Intel and AMD systems.

## 🚀 Getting Started

### Quick Start (Executable)
1. Download the latest release from the [Releases](../../releases) page.
2. Extract the archive to a folder of your choice.
3. Disable temporary antivirus shields (some tools flag low-level registry/hardware access).
4. Run `HWID_Spoofer.exe` as **Administrator**.
5. Click **Spoof**, wait for the process to complete, and restart your PC.
